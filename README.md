# 🌌 My Little Universe — Image Gallery

My Little Universe is a personal image gallery created using HTML, CSS, and JavaScript as part of my CodeAlpha internship.

The gallery brings together images inspired by nature, books and novels, and the cartoon world.

## Features
- Category-based image filtering
- Image pop-up (lightbox) view
- Next and previous navigation buttons
- Captions for images
- Interactive gallery design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project files.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.

Developed as part of my CodeAlpha internship to practise front-end web development.
